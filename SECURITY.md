# Security reports

Report suspected vulnerabilities privately to **LoyalLambChops@gmail.com**, with subject **GhostData security report**. Include affected version, impact and minimal reproduction steps. Do not include credentials or another person's match data, and do not publish exploit details in a public issue before coordination.

This is a volunteer project; no response-time guarantee or bug bounty is offered. Fixes target the latest supported beta. Only obtain release packages from the project's linked GitHub Releases page. Initial builds are unsigned; published SHA-256 hashes detect byte differences but are not a publisher signature.
