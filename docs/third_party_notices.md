# Third-party notices

The current complete [third-party notices](../THIRD_PARTY_NOTICES.md) cover UnitySpy, Avalonia dependencies and game ownership.

GhostData's optional selected-deck sensor uses the MIT-licensed **UnitySpy** project from Zero-to-Heroes. The build script downloads a pinned upstream revision and preserves the upstream license beside the built sensor. GhostData does not bundle the upstream source archive in the release package until the sensor build script is run locally.
